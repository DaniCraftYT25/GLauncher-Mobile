# GLauncher Mobile

GLauncher Mobile es un lanzador de juegos para Android. Este proyecto está diseñado para proporcionar una forma fácil de gestionar e iniciar tus juegos.

## Características

*   **Lanzador de juegos:** Inicia tus juegos favoritos desde una única aplicación.
*   **Gestión de versiones:** Posiblemente permite gestionar diferentes versiones de juegos.
*   **Soporte para Minecraft:** Parece tener un enfoque especial en Minecraft.

## ¿Cómo usar?

1.  Clona este repositorio.
2.  Abre el proyecto en Android Studio.
3.  Compila y ejecuta la aplicación en tu dispositivo o emulador Android.
